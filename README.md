# Starfield Record Types

A plain-English guide to every record type in `Starfield.esm` (the four-letter codes such as GMST, KYWD, NPC_, CELL and QUST), read from the game's main data file (game version 1.16.244.0).

**View it here:** https://taosecurity.github.io/starfield-record-types/

- 180 record types in 10 categories, each with its xEdit name, a short explanation, its record count and a real editor ID from `Starfield.esm`.
- A short intro to plugins, records, FormIDs and editor IDs, groups, and how overrides and load order cause conflicts.
- A table of the record types console commands work with, linked to the [Starfield Console Commands](https://taosecurity.github.io/starfield-console-commands/) page.
- Search across codes, names, explanations and editor IDs.

Made by Richard Bejtlich of [Richard Presents Starfield Essentials](https://www.youtube.com/@RichardBejtlich).

## Notes

- This is an unofficial guide, not made or endorsed by Bethesda. Starfield is a trademark of ZeniMax Media.
- The record type names are the ones xEdit uses. The explanations are our own; types marked "not sure" are little documented, so treat those as a best guess.
- Only names, counts and editor IDs are shown. Mods and the add-on files add more records.
- The list is regenerated after game updates.

The page is a single self-contained `index.html` with no external dependencies. Its code (layout and search) is MIT licensed; see `LICENSE`.
