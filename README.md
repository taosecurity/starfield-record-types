# Starfield Record Types

This page is a plain-English guide to every record type in `Starfield.esm`, the four-letter codes such as GMST, KYWD, NPC_, CELL and QUST. It was read from the game's main data file (game version 1.16.244.0).

**View it here:** https://taosecurity.github.io/starfield-record-types/

- The page lists 180 record types in 10 categories. Each one has its xEdit name, a short explanation, its record count and a real editor ID from `Starfield.esm`.
- A short introduction explains plugins, records, FormIDs and editor IDs, groups, and how overrides and load order cause conflicts.
- A table shows the record types that console commands work with, linked to the [Starfield Console Commands](https://taosecurity.github.io/starfield-console-commands/) page.
- You can search across codes, names, explanations and editor IDs.

Richard Bejtlich of [Richard Presents Starfield Essentials](https://www.youtube.com/@RichardBejtlich) made this page. More Starfield tools and references are on the [Richard Presents Development Hub](https://taosecurity.github.io/).

## Notes

- This is an unofficial guide, not made or endorsed by Bethesda. Starfield is a trademark of ZeniMax Media.
- The record type names are the ones xEdit uses. The explanations are our own; types marked "not sure" are little documented, so treat those as a best guess.
- The page shows only names, counts and editor IDs. Mods and the add-on files add more records.
- The list is regenerated after game updates.

The page is a single self-contained `index.html` with no external dependencies. Its code (layout and search) is MIT licensed; see `LICENSE`.
